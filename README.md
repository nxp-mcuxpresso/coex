# MCUXpresso SDK : mcuxsdk-middleware-wireless-coex

## Overview

This repo contains coex examples for NXP RT platform.
The repository contains:

- NXP sdk next generation CMake&kconfig files.
- linker script files for coex examples
- configuration files for other middleware (lwip, freertos, mbedtls, etc..)
- coex source files.

## Documentation

Overall details can be reviewed here:[MCUXpresso SDK Online Documentation](https://mcuxpresso.nxp.com/mcuxsdk/latest/html/introduction/README.html#mcuxpresso-sdk)
